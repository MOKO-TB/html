1. 外部样式表是用什么标签引入到 HTML 中的？
用<link>标签
如：<link rel="stylesheet" href="styles.css">
2. 想让页面内容在屏幕正中间水平垂直居中，最少需要哪几行 CSS？
{
    display: flex;
    justify-content: center;
    align-items: center;
}
3. padding: 30px 是什么意思？它和 margin 有什么区别？
padding:内边距，30px为大小，margin是外边距

4. border-radius: 50% 有什么用？什么情况下能把一个元素变成圆形？
是让元素的四个角变成圆角有弧度的角，50%是圆角半径。当元素为正方形时会变成一个圆形

5. CSS 中 color 和 background 分别控制什么？可以用哪些格式来写颜色值？
color是文字的颜色
background是背景的颜色

6. font-family、font-size、font-weight 分别控制字体的什么属性？
font-family是字体类型
font-size是字的大小
font-weight是字的粗细

7. box-shadow: 0 5px 20px rgba(0,0,0,0.1) 里的四个值分别代表什么？
0指的是盒子的X轴的偏移量，5px是Y轴的，20px是模糊程度，rgb是阴影的颜色

8. 什么是 CSS 类选择器？怎么给同一个元素添加多个类？
以.开头，给拥有对应class的元素添加样式。
给同一个元素加多个类:在class 属性里用空格分隔

9. cursor: pointer 有什么作用？还有哪些常见的 cursor 值？
鼠标悬停功能，可以让鼠标形状改变
其他常见值：
default：默认箭头（标准状态）。
text：文本输入光标（I 字形）。
move：移动十字箭头（表示可拖动）。
not-allowed：禁止符号（红色圆圈斜杠）。
grab / grabbing：抓手（拖拽时使用）。

10. CSS 样式中的冒号 : 和分号 ; 分别表示什么？写错会有什么后果？
冒号：是赋值的，分号；是结束的意思
写错导致无法结束，代码无法正常运行
